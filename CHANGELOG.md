# Changelog

## 0.4.1

- Show the installed ESM version on the Status tab for easy post-update confirmation.
- No changes to health checks, compatibility behavior, settings, collector credentials or schedules.

## 0.4.0

- Add WordPress update discovery from published stable GitHub releases with mandatory packaged ZIP assets.
- Exclude prereleases, drafts, loose tags, development branches and generated source archives from update delivery.
- Bundle Plugin Update Checker 5.7 with its license notices.
- Add public release packaging, dependency provenance and rollout/rollback documentation.
- Preserve per-site settings, signing keys, historical records and existing auto-update preferences.

## 0.3.0

- Add administrator-only Admin Bar health indicators and monitor/settings links using recorded evidence.
- Mark old passing local evidence stale while retaining recorded failures.

## 0.2.9

- Remove retired automatic-repair presentation from current status views.

## Earlier versions

Initial stylesheet health, cache compatibility, purge history, alarm email and signed collection functionality.
